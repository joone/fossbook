---

Fossbook Comics is the live demo for [Fossbook](https://github.com/joone/fossbook),
a Markdown-based publishing tool for comics, illustrated stories, and articles.

The artwork used throughout this demonstration is from
[F/OSS Comics](https://fosscomics.com), the project Fossbook originally powered.
It is included here only as credited demonstration artwork. For your own
publication, use artwork that you created or are licensed to publish.

## Try Fossbook

1. Install Fossbook with `npm install -g fossbook`.
2. Create a publication with `fossbook init`.
3. Write a post in `content/posts/`, keeping its artwork in that post's `images/`
   directory.
4. Run `fossbook serve` to preview it, then `fossbook build` to generate a static
   site.

Read the [source Markdown for this demo](https://github.com/joone/fossbook/tree/main/content)
and the [complete Fossbook Markdown guide](https://github.com/joone/fossbook/blob/main/fossbook_markdown.md).
