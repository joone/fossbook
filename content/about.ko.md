Fossbook 만화는 만화, 그림 이야기, 글을 위한 마크다운 기반 출판 도구인
[Fossbook](https://github.com/joone/fossbook)의 라이브 데모입니다.

이 데모에서 사용하는 그림은 Fossbook으로 처음 제작한 프로젝트인
[F/OSS Comics](https://fosscomics.com)의 작품입니다. 출처를 밝힌 데모용
그림으로만 이곳에 포함했습니다. 자신의 출판물에는 직접 만들었거나 게시
권한이 있는 그림을 사용하세요.

## Fossbook 사용해 보기

1. `npx fossbook init`으로 출판물을 만듭니다.
2. 새 출판물에서 `npm install`을 실행합니다.
3. `content/posts/`에 글을 쓰고 그림은 해당 글의 `images/` 디렉터리에
   보관합니다.
4. `npm run start`로 미리 본 다음 `npm run build`로 정적 사이트를
   생성합니다.

[이 데모의 마크다운 소스](https://github.com/joone/fossbook/tree/main/content)와
[Fossbook 마크다운 전체 안내서](https://github.com/joone/fossbook/blob/main/fossbook_markdown.md)를
읽어 보세요.
